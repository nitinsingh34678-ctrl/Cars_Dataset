# Cars Dataset Analysis 📊

This project performs Exploratory Data Analysis (EDA) on a cars dataset
using Python. The goal is to analyze car prices, fuel types, and
manufacturer trends using graphs and statistics.

## Dataset Features
- Customer ID
- Car Model
- Fuel Type (Petrol / CNG / Electric)
- Price
- Manufacturer

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## What I Did
- Cleaned the dataset
- Analyzed price distribution
- Visualized fuel-type comparison
- Created graphs for better insights

## How to Run
1. Open the notebook in Jupyter Notebook
2. Run all cells sequentially
